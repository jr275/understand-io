# Implementation status: Understand.io

_Canonical status of the current code, including the second brief (intelligent reading). Last updated 2026-10-17 at the commit that contains this file. Every row was last verified on 2026-10-17 unless its evidence column says otherwise. The statuses and ids were taken from `docs/audit/requirements-traceability.md` when this file was written; if they ever differ, re-verify before trusting either._

**Statuses (exactly these six):** `NOT IMPLEMENTED` · `IMPLEMENTED, NOT VERIFIED` · `PARTIALLY IMPLEMENTED` · `VERIFIED WORKING` · `BLOCKED` · `NOT OBSERVABLE`.

**Rules applied.** A mock-based test alone never earns `VERIFIED WORKING` for an external integration: those rows are `BLOCKED` or `IMPLEMENTED, NOT VERIFIED` until the real service has been used. Browser capabilities name the browser: the only real browser was Google Chrome 155 on macOS (the user's own, driven through an extension) plus Playwright's bundled Chromium. Features that need human perception (hearing audio, speaking into a microphone, touching a phone) have **not** had independent human verification; no row claims it.

**Legend for the verification method:** U unit test, I integration with the real local PostgreSQL, E Playwright end to end (fakes for speech engine, microphone, model), R recorded manual check in real Chrome 155, S static (types, lint, build), axe automated accessibility scan.

## Known deviations from the reference

- Accounts use a self-contained Google OAuth flow instead of Clerk, and only when credentials are configured. There is no MCP agent connection.
- `/?url=` and `/?save=` fill the field and wait for the reader to press Read, instead of importing at once (a security fix: SEC-6).
- The top-bar Add button, drop-anywhere import and the end-of-text "Read something else" strip are additions requested by the user, not reference features.
- Topic icons and cover illustrations are procedural SVG, not the reference's painted images. The partner logo was removed from the top bar at the user's request (the model provider is still named in the footer and the privacy notes).
- Highlight and underline shortcuts are Shift+H and Shift+U; plain letters start a question, as in the reference.
- The Listen setting is off by default, so the top-bar headphones button only appears after it is switched on; `L` always works.
